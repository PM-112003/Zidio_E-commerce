##### Packages included and why them?
    - express (creating express application)
    - nodemon (reflecting file save in browser)
    - dotenv (accessing environmetal variables from .evn file)

##### key notes

environmental variables - these are the data, especially the sesitive one, added in the '.env' file. We use dotenv package to access these files. 

.gitignore file - this file is ignored by the git hence not tracked by the git. hence, any file name mentioned in this file will not be trancked by the git. '.env' file and node_modules folder are added in the gitignore file.
